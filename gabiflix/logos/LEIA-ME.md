# Logos dos botões

Coloque aqui um PNG sem fundo para cada serviço, com exatamente estes nomes:

| Serviço | Arquivo |
|---|---|
| Netflix | `netflix.png` |
| Disney+ | `disney.png` |
| Prime Video | `prime.png` |
| HBO Max | `hbo.png` |
| Apple TV+ | `appletv.png` |
| Paramount+ | `paramount.png` |
| Globoplay | `globoplay.png` |
| Claro Video | `clarovideo.png` |

Sem o arquivo, o botão continua só com o nome. Use logos claros (brancos ou coloridos), porque o fundo do botão é escuro.
